# Nadid Azwad

My portfolio: a file tree that grows as a dithered plant. React + Vite + three.js (React Three Fiber), Tailwind v4, deployed on Vercel.

```sh
pnpm install
pnpm dev      # http://localhost:5173
pnpm build    # typecheck + production build to dist/
pnpm test     # vitest
```

The fonts (PP Neue Montreal, PP Mondwest, PP NeueBit from Pangram Pangram) aren't in the repo. Put your own copies in `public/fonts/` to run it locally.

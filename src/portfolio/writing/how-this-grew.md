This plant started as a screen recording of a file tree growing like a vine. I rebuilt it from nothing in three.js.

Every folder is a branch. Open one and a new branch grows **out of the folder itself**, fatter at the opening when there's more inside. Close it and it snaps back.

The plant is drawn as lit tubes and leaves, then **dithered onto a pixel grid that's locked to the world**, so the pattern never crawls when you drag. The picture only ever slides by whole device pixels.

The icons sit on the same grid as the plant: one icon pixel is one dither cell.

Two other things in this folder need a word.

## grand-theft-pokemon

My friend **Redwan** asked me to make a game for his accounting club. Last year their event had a Pokémon theme and this year's is GTA, so he wanted a game that carries you from one to the other. Level one is **a Pokémon parody full of accounting puns and jargon**. Level two is **a GTA 2 ripoff**, and it's the hard one on purpose: finishing the game was how you'd sign up for the event.

**The club never ended up using it.** It still runs, so it lives here.

## grow-your-repo

This one came to me out of nowhere: **any repo's file tree, grown as a plant** the way this site grows mine. **Now it's built.** Paste a link to a public GitHub repo and its tree grows in; open a folder and it grows a branch of its own.

The hard part was placing it. On this site I placed every point of the plant by hand, but there the code has to place **any repo's tree, however big**. Each branch is a seeded walk that steers round the names already there, so the same repo always grows the same plant. The code is [on GitHub](https://github.com/nadidazwad/grow-your-repo).
